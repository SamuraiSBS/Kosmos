# КосмоХакатон — MVP сайта-игры

Интерактивная пиксельная игра для демонстрации возможностей спутникового мониторинга сельскохозяйственных территорий.

## 🎮 Концепция

Это вертикальный срез (vertical slice) игры в духе Stardew Valley, через которую пользователь:
- Исследует проблемные участки поля
- Анализирует спутниковые данные
- Принимает решения
- Наблюдает последствия своих решений

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка production-версии
npm run build

# Предварительный просмотр сборки
npm run preview
```

## 📱 Платформа

**Приоритет:** мобильные устройства  
**Основное разрешение:** 390 × 844 px  
**Диапазон адаптации:** 320–500 px ширины

На desktop показывается мобильный интерфейс по центру экрана.

## 🛠 Технологический стек

- **React** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **CSS Modules** — стилизация
- **Zustand** — управление состоянием
- **Framer Motion** — анимации интерфейса

## 🎯 Игровой сценарий MVP

```
Космос
  ↓
Приближение к Земле
  ↓
Проход через облака
  ↓
Посадка на поле
  ↓
Intro от NPC-помощника
  ↓
Обнаружение проблемного участка
  ↓
Спутниковый анализ
  ↓
Выбор решения
  ↓
Визуальное изменение участка
  ↓
Награда (XP + Farm Health)
  ↓
Возвращение на карту
```

**Время прохождения:** 1–2 минуты

## 🎨 Система ассетов

Все визуальные объекты используют единый интерфейс `GameAsset`:

```tsx
<GameAsset
  id="farm-house"
  asset="farmHouse"
  width={96}
  height={80}
/>
```

### Текущий статус ассетов

**Сейчас (MVP):** цветные прямоугольники, круги, CSS-фигуры, emoji  
**В будущем:** PNG / WebP / SVG спрайты

### Пример asset registry

```ts
export const assetRegistry = {
  player: {
    type: "placeholder",
    label: "PLAYER",
  },
  fieldHealthy: {
    type: "placeholder",
    label: "FIELD",
  },
  fieldCritical: {
    type: "placeholder",
    label: "DRY",
  },
};
```

Замена placeholder на реальные ассеты происходит **без изменения игровой логики**.

- ✅ Поле A (активное, 5×5 тайлов)
- 🔒 Поле B (заблокировано)

- ✅ Водоём

- ✅ Дороги

### Состояния поля

```ts
type FieldState =
  | "healthy"    // Зелёный
  | "warning"    // Жёлтый
  | "critical"   // Оранжевый
  | "resolved";  // Насыщенный зелёный
```

## 📊 Game State

Хранится в Zustand store + localStorage:

```ts
{
  xp: number;
  farmHealth: number;      // 0–100%
  currentMission: string;
  missionProgress: Record<string, number>;
  fieldStates: Record<string, FieldState>;
  introCompleted: boolean;
  selectedField: string | null;
  analysisCompleted: boolean;
}
```

## 🎯 Первая миссия

**ID:** `mission-01`  
**Название:** "Аномалия на северном поле"  
**Описание:** "Исследуйте северный участок поля"  
**Награда:** 120 XP

**Цель:** найти проблемные тайлы на севере поля A, провести анализ, выбрать правильное решение.

## 🔍 Спутниковый анализ

Показывает mock данные:

```
Состояние растений:    72%
Влажность:            41%
Изменение индекса:    -18%
Риск:                 Высокий
```

**Предполагаемая проблема:** Недостаток влаги

## ✅ Правильное решение

**Варианты:**
1. 💧 Увеличить полив ✅ (правильно)
2. 🌱 Внести удобрения
3. 👁 Продолжить наблюдение

**Результат правильного выбора:**
- +120 XP
- Farm Health: 72% → 86%
- Поле: `critical` → `resolved`
- Визуальная анимация изменения тайлов

## 🎨 Визуальный стиль

**Цветовая палитра:**
- 🟢 Зелёный — здоровые территории
- 🟡 Жёлтый — средний уровень
- 🟠 Оранжевый — проблемные территории
- 🔵 Голубой — вода / технологии
- 🔷 Тёмно-синий — космос
- ⬜ Кремовый — UI панели

**Стиль:** пиксельная эстетика
- Минимальные border-radius
- Чёткие границы
- Небольшие тени
- Крупные игровые кнопки
- Ступенчатые элементы

## 🚫 Что НЕ реализовано в MVP

- Регистрация / авторизация
- Backend / база данных
- Мультиплеер
- Инвентарь / магазин
- Строительство
- Боевая система
- Сложная физика / collision detection
- Procedural generation
- Десятки культур / сезонов
- Открытый мир
