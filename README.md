# Kosmohackathon MVP

Проект, созданный для космического хакатона. Это веб-приложение на React с визуализацией спутниковых данных и игровыми элементами.

## Технологии

- **React 19** - библиотека для создания пользовательских интерфейсов
- **TypeScript** - типизированный JavaScript
- **Vite** - современный сборщик проектов
- **Framer Motion** - библиотека для анимаций
- **Zustand** - менеджер состояния приложения

## Структура проекта

```
├── src/
│   ├── app/              # Основной компонент приложения
│   ├── components/       # Переиспользуемые компоненты
│   ├── game/             # Игровая логика и типы
│   ├── scenes/           # Сцены приложения (Intro, Map, Analysis, etc.)
│   ├── styles/           # Глобальные стили
│   └── main.tsx          # Точка входа
├── index.html            # HTML шаблон
├── package.json          # Зависимости и скрипты
├── tsconfig.json         # Конфигурация TypeScript
└── vite.config.ts        # Конфигурация Vite
```

## Установка и запуск

### Требования

- Node.js (версия 18 или выше)
- npm или yarn

### Шаг 1: Установка зависимостей

Откройте терминал в папке проекта и выполните:

```bash
npm install
```

### Шаг 2: Запуск в режиме разработки

Для запуска локального сервера разработки:

```bash
npm run dev
```

После запуска откройте браузер и перейдите по адресу: `http://localhost:5173`

### Шаг 3: Сборка для продакшена

Для создания оптимизированной production-версии:

```bash
npm run build
```

Собранные файлы появятся в папке `dist`.

### Шаг 4: Предварительный просмотр production-версии

Чтобы протестировать production-сборку локально:

```bash
npm run preview
```

## Доступные команды

| Команда | Описание |
|---------|----------|
| `npm run dev` | Запуск сервера разработки |
| `npm run build` | Сборка проекта для продакшена |
| `npm run preview` | Предпросмотр production-сборки |

## Особенности проекта

- **Интерактивные сцены**: Приложение состоит из нескольких сцен (Intro, Space, Map, Analysis, Decision, Result)
- **Анимации**: Плавные переходы между сценами благодаря Framer Motion
- **Управление состоянием**: Zustand для глобального состояния приложения
- **Типизация**: Полная поддержка TypeScript для лучшей разработки
